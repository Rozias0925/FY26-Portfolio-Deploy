# Factor GCN Integration Interface

This directory defines an abstract interface for a potential private connection to the original Factor GCN research project. It contains an interface stub only; the original research implementation, trained weights, and financial data are not included.

`factor_gcn.py` specifies an `infer` method and reports the integration status as `NOT INTEGRATED`. The synthetic API uses the independent computation in `demo/`.

Any future implementation requires a separate review of research ownership, data permissions, collaboration obligations, and the intended local use. The current repository preserves that boundary through the unimplemented interface.

See the [main project overview](../README.md) and [data policy](../docs/DATA_POLICY.md) for the implemented system and its scope.
