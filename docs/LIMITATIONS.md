# 技術限制與尚未宣稱的能力

本專題展示 API、模型服務化、前後端分工、容器設定、測試與可重現性的工程流程。實際演算法是 `demo_synthetic_graph_model`：自行產生合成資料、固定參數、一層訊號混合。原始 Factor GCN 為 **NOT INTEGRATED**。

## 研究與模型

- 沒有載入原 Factor GCN code、研究資料或已訓練權重；也沒有重現原論文實驗。
- 固定參數示範沒有神經網路訓練。`training_window` 指 120 個合成日的統計校準區段，不能當作 GCN 已訓練的證據。
- 6 個資產是 `SIM-01` 等虛構標籤。合成資料依預設分布與 seed 產生，沒有外部真實價格、因子、交易量或企業資料。
- 用相關絕對值建圖會把正負相關都視為連結；一層固定訊息混合是教學選擇，沒有經過真實市場有效性驗證。
- `low`、`balanced`、`high` 改變波動懲罰、softmax 溫度與集中度；不保證每次實現波動或回落依名稱排序。

## 評估與可重現性

目標權重只用前 120 日建立，以後 60 日每日按相同目標權重計算，隱含每日權重重設；不是買入後自然持有。沒有模擬再平衡執行、周轉率與成本。這個切分降低示例中的直接未來資訊使用，但不能證明市場泛化、因果推論或正式研究有效性。60 日樣本很小，年化指標只是按 252 日慣例縮放。

指標不含交易成本、稅、滑價、流動性、市場衝擊、可交易限制、下架偏誤或真實資產約束。Sharpe 使用無風險利率 0。合成的正收益或漂亮曲線不代表投資優勢。

Scenario B 刻意在相同 seed 下共享 Scenario A 的校準資料，但改變未來評估分布；因此配置可以相同、評估結果不同。這是展示分布改變與外推限制的設計，不是 API 沒更新。

相同 seed、參數、程式與依賴可重現結果。NumPy、Python、平台浮點與間接依賴差異仍可能產生小量數值差異；沒有宣稱任何平台的位元完全一致。固定頂層依賴也不等於整個 supply chain 已鎖定或安全。

## 網頁與本機服務

| 元件 | 做得到 | 範圍限制 |
|---|---|---|
| 靜態教學網站 | 章節、術語、瀏覽器合成示意 | 不呼叫 Python 模型；不是即時 Factor GCN 推論 |
| FastAPI | 嚴格參數、合成計算、JSON、OpenAPI | 本機使用，沒有公開網路身分驗證、配額或正式營運監控 |
| Dashboard | 透過 HTTP 呼叫 API，展示圖表與 JSON | 不是交易平台，沒有資料上傳或使用者持倉分析 |
| Docker Compose | 描述兩服務環境與 loopback port | 設定存在不等於本機容器已驗證成功；以 testing 記錄為準 |
| 測試 | 檢查數值、契約、邊界與整合 | 測試通過不等於金融業 production、完整資安或法律認證 |

Dashboard 保留上次成功結果供比較；變更參數或最新請求失敗時會標示舊結果。API 離線時會顯示連線問題。此狀態管理不提供永久存檔、分散式 session 或多租戶隔離。

`/docs` 使用自製的本機 API explorer，沒有載入 Swagger CDN；`/openapi.json` 提供標準 schema，`/redoc` 未啟用。API 文件與合成計算在安裝依賴後可於本機運作。依賴安裝與 Docker 基礎映像下載仍需要網路；沒有宣稱首次建置可完全離線。
